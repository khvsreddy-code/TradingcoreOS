# TradingCoreOS v12 — TradingView Public Script Catalog

This release adds a real TradingView Community Scripts catalog to the Indicators page.

Selected publications are linked to their original TradingView pages with author/category metadata. The app does not copy protected or invite-only scripts. Where TradingCore already has an independent equivalent, the UI can add that native study to the chart.

The catalog includes public/open-source publications covering RSI divergence, fair value gaps, order blocks, volume profile, market structure, liquidity-sweep concepts and VWAP-derived analysis.
