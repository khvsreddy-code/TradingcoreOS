# Documentation Archive

The active source of truth is the five documents in the parent docs/ directory:

- 01_CORESPIRIT.md
- 02_DATA_AND_PERFORMANCE.md
- 03_VELA_AND_CHARTING.md
- 04_INDICATORS_AND_PLATFORM.md
- CORESPIRIT_BUILD_TRACKER.md

Archive policy:

- history/ — retained chronological implementation notes that are still useful for lineage.
- legacy/ — superseded architecture documents that preserve distinct historical context.
- reference/ — small historical contracts/deep dives whose concepts may still be referenced.
- Deprecated duplicate trackers, repair dumps and stale vendor-specific notes are removed rather than kept as a second source of truth.

Do not treat archived implementation claims as current status. Current architectural truth and open performance debt belong in the active documents and source contracts.
