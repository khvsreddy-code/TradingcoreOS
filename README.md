# TradingCore

TradingCore is a professional trading platform website. This repository contains the web foundation with Next.js App Router, strict TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Project boundaries

- Next.js App Router shell, strict TypeScript, Tailwind, Framer Motion, Lucide, ESLint, and Prettier are configured.
- Website-focused architecture without modular app/platform infrastructure.
- Landing page components and design system foundation are implemented.

## Commands

- `pnpm dev` — run the local development server.
- `pnpm lint` — run ESLint.
- `pnpm typecheck` — verify TypeScript without emitting files.
- `pnpm build` — create the production build.
- `pnpm format:check` — validate formatting.

## Architecture references

The original Phase 0 architectural documents are retained in [`outputs/`](./outputs/) for reference. Note that the modular app/platform architecture described in these documents has been simplified for this website-only implementation.
